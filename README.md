# Проект «Учёт книг»

Простая консольная программа на Python для учёта количества выданных книг в библиотеке. Проект создан в рамках практического задания по регрессионному тестированию и включает две версии приложения (`app_v1.py` и `app_v2.py`), а также отчёт о тестировании (`otchet.md`).

## Как запустить программу

1. Убедитесь, что на компьютере установлен **Python 3**.
2. Скачайте репозиторий или скопируйте файлы себе на компьютер.
3. Откройте терминал (командную строку) в папке с проектом и выполните команду:

Для запуска первой версии:
```bash
python app_v1.py
```

Для запуска обновлённой версии:
```bash
python app_v2.py
```

## Как пользоваться меню

После запуска программа выводит список доступных действий и ожидает ввода цифры команды:

* `1` — **Выдать одну книгу** (увеличивает счётчик выданных книг на 1).
* `2` — **Показать, сколько книг выдано** (выводит текущее значение счётчика).
* `3` — **Сбросить счётчик до 0** (обнуляет количество выданных книг).
* `4` — **Вернуть книгу** *(доступно только в `app_v2.py`)* — уменьшает счётчик на 1. Если выданных книг нет (`0`), выводит предупреждение.
* `0` — **Выход** (завершает работу программы).

При вводе любых других символов программа выведет сообщение `Неизвестная команда` и сохранит текущее значение счётчика.
